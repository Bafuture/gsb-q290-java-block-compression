## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们把大文件整体压缩后想读中间一段必须从头解压，希望分块压缩并支持随机定位。请从零实现一个分块压缩与随机访问组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 支持把数据切成固定大小的块分别压缩，每块记录压缩后偏移与长度形成索引；2) 支持随机访问：给定原始偏移与长度，定位到相关块并只解压这些块，不得解压整个文件；3) 支持跨块读取：请求范围跨越多个块时要正确拼接结果，边界不得重复或遗漏；4) 支持每块校验和，损坏块要能定位并明确报错；5) 支持并发读取：多线程读取不同块互不阻塞，同一块的并发请求只解压一次；6) 支持块大小配置，并给出块大小对压缩率与随机读取耗时的权衡数据；7) 支持流式写入：边写边生成索引，写入完成后立即可随机读取；8) 测试覆盖分块压缩、索引生成、随机与跨块读取、损坏检测、并发读取与权衡数据；`mvn -q verify` 一条命令跑通。
